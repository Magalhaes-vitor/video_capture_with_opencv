# Video Capture with OpenCV

This project demonstrates how to use OpenCV in Python to capture and process video frames. It enables you to read video from your webcam, apply basic image processing techniques, and display the output in real-time.

## Features

- Capture video from webcam using OpenCV
- Apply real-time processing on video frames
- Save the captured video to a file

## Installation

1. Clone the repository:

```bash
git clone https://github.com/Magalhaes-vitor/video_capture_with_opencv.git
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

## Usage

Run the script to capture video from your webcam:

```bash
python video_capture.py
```

Press `Q` to quit the video stream.

## Libraries Used

- `opencv-python`
